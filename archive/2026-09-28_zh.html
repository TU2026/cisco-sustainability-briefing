Cisco 可持续发展情报简报

越南《电力法》修订、东盟电网加速推进、Cisco 动态产品碳足迹追踪脱碳电网

覆盖窗口：2026年9月22日 – 9月28日 · 搜索语言：英文 · 主题数：5 · 致：dit2@cisco.com

执行摘要

越南电力市场架构正被再次改写。2026年9月21日，越南国会常委会审议《电力法》部分条款修订补充草案，拟修改2024年《电力法》23项条款，引入竞争性投资人遴选和竞价电价机制，向私人资本/PPP开放输电投资，并将海上风电、电池储能及直购电（DPPA）纳入更明确的法律框架。同一周内，越南电力集团河内公司（EVN Hanoi）投运了全国首批电网级电池储能系统（BESS）——总容量50 MW / 100 MWh，分布在河内五座110 kV变电站——胡志明市人民议会也于9月22日讨论DPPA实施条例，呼吁由每笔交易自建专线转向租用或共享国家电网、采用多回路输电技术。

在区域层面，2026年9月22–24日雅加达 Enlit Asia 2026 期间，东盟电网从规划文件进入政策压力阶段。区域能源领袖推动总额达7,640亿美元的东盟电网建设，而吉宝同日披露计划开发印尼廖内群岛2 GW光伏+公用事业级储能项目，通过海底电缆接入新加坡裕廊岛的美林茂热电联产电厂。在 Cisco 方面，公司发布了动态产品碳足迹（PCF）方法，依据国际能源署（IEA）电网数据和预测调整硬件碳排放，并正在接受 Fraunhofer 的方法学审查。该进展恰逢 TNFD 发布2026年度现状报告：按 TNFD 建议披露自然相关信息的企业数量已翻倍至1,002家，并发布针对数据中心与半导体企业的行业指引，要求企业在选址阶段评估水和土地风险。

Top 3 本周最值得行动的发现
1 · 越南修订《电力法》：扩大DPPA、向私人资本开放输电、为储能与海上风电奠定法律基础
紧迫性/关联度 9.0
2026年9月21日，越南国会常委会审议《电力法》部分条款修订补充草案。草案修改23项条款、废止3项行政审批、新增1项，核心转向竞争性定价与风险分担：引入投资人遴选和竞价电价机制，允许输电项目采用PPP模式吸引社会资本，并明确涵盖海上风电、储能系统及直购电（DPPA）。越南现行《电力法》已引入容量电价与电量电价相结合的两部制电价；本次修订进一步细化交叉补贴退出路径、可再生能源/储能/社会资本投资输电设施的扶持性价格机制。9月22日，胡志明市人民议会讨论DPPA实施条例草案，代表们建议由“每笔交易自建专线”转向租用或共享国家电网、采用多回路输电技术，以降低土地征用与投资成本。与此同时，河内电力总公司9月已完成五座110 kV变电站共50 MW / 100 MWh电网级BESS的安装调试，越南工贸部正研究居民及工业分时电价以管理高峰负荷。
对 Cisco 的重要性：Cisco 在北宁、海防、同奈与平阳省的 EMS/ODM 供应商如今面对的法律环境明确将 DPPA、储能共址和私人输电投资纳入其中。行动窗口：要求越南采购团队在所有新建工厂及屋顶光伏招标文件中纳入 DPPA 资格、电网租赁选项和储能共址方案，并按竞价电价与两部制电价建模电力成本。

2 · Enlit Asia 2026 加速东盟电网；吉宝规划2 GW印尼–新加坡光伏+储能海底电缆
紧迫性/关联度 8.8
2026年9月22–24日雅加达 Enlit Asia 2026 期间，区域能源领袖推动加速实施东盟电网（APG）。APG 构想始于1997年，目标2045年联通东盟各国电网，东盟估计发电与输电总投资需求达7,640亿美元，世界银行估算约8,000亿美元。东盟当前跨境互联容量约7.7 GW，计划到2040年翻倍。需求增长部分来自数据中心（部分设施需求超过1 GW）和电动汽车。泰国电力监管机构 Warit Rattanachuen 强调，各国在深化跨境交易前须先确保国内电力安全。同期，吉宝于9月19日披露计划开发印尼廖内群岛2 GW光伏项目，配套公用事业级储能及海底电缆，接入新加坡裕廊岛美林茂热电联产电厂（KMC）。吉宝已获得新加坡能源市场管理局（EMA）从印尼进口300 MW低碳电力的有条件许可。新加坡目标到2035年进口约6 GW低碳电力，目前已有六家公司获准从印尼合计进口3 GW，另有七家公司获得有条件批复，规划合计6.25 GW。印尼要求清洁能源出口商每五年更新出口许可，仍是开发商面临的关键监管不确定性。
对 Cisco 的重要性：若东盟电网及印尼–新加坡走廊落地，Cisco 在越南与泰国的供应商集群将有机会通过跨境可再生 PPA 与绿证采购电力，降低对国家电网脱碳进度的单一依赖。行动窗口：跟踪新加坡6 GW进口路线图及印尼出口法规进展，并请区域能源顾问为越南南部供应商园区建模跨境输电场景。

3 · Cisco 发布随电网脱碳动态调整的产品碳足迹方法
紧迫性/关联度 8.5
Cisco 于2026年9月22日在博客中阐释从静态产品碳足迹（PCF）向动态 PCF 的演进。该方法首先识别碳排放热点（印刷电路板、集成电路、测试与组装能耗），然后将排放中可归因于供应商用电的部分隔离出来，再使用全球电网数据和国际能源署（IEA）预测动态调整，从而可以回溯（backcast）历史 PCF 并预测（forecast）未来随着生产电网脱碳而下降的排放。Fraunhofer 已批判性审阅 Cisco 静态 PCF 方法以确保与 ISO 14067 对齐，并计划审阅动态计算方法。合作伙伴可通过 Cisco 价格清单 API 获取 PCF 数据，客户可通过 Product Sustainability API 直接访问，以帮助追踪范围三排放、设定净零目标并支持采购决策。
对 Cisco 的重要性：动态 PCF 为 Cisco 提供了将供应商可再生能源与 DPPA 进展转化为可量化范围三减排的具体杠杆，直接支持 FY30 范围三减排30%及2040年净零目标。行动窗口：将 Product Sustainability API 整合进供应商沟通，让关键 EMS/ODM 合作伙伴看到越南、泰国和马来西亚电网脱碳如何降低 Cisco 硬件碳足迹。

战略建议

短期（0–3个月）

  • 越南供应商 DPPA/储能 操作手册：向富士康、Pegatron、NIDEC 与 AVC 采购团队 briefing《电力法》修订要点；要求所有新建工厂及屋顶光伏招标文件纳入 DPPA 资格、电网租赁选项和 VPP 友好控制接口，并按竞价电价和两部制电价建模电力成本。
  • 东盟电网跟踪清单：指定区域能源顾问跟踪 Enlit Asia 后续进展、印尼出口法规时间表及新加坡6 GW进口路线图，并为越南南部供应商园区输出首版跨境输电场景分析。
  • 动态 PCF 供应商试点：利用 Cisco Product Sustainability API，向5–10家核心 EMS/ODM 供应商展示电网脱碳假设如何影响产品碳足迹，并要求其对齐自身可再生能源采购。

中期（3–12个月）

  • 区域低碳采购联盟：评估 Cisco 是否可以加入或赞助面向越南/泰国的跨境可再生电力采购买方联盟，借助印尼–新加坡及老挝–泰国–马来西亚–新加坡走廊为供应商 PPA 增加稳定性。
  • CDP Water Security Module 5.11 SOP 定稿：将 TNFD 科技行业场地级水/土地筛查、Water Scopes 1–3 边界逻辑及新加坡/泰国水回收基准整合进供应商评估 SOP，对水资源压力流域内晶圆厂设定明确的回收/再利用阈值。
  • 自然与碳披露路线图：制定 TNFD/ISSB 一致的自然与水风险披露路线图，引用千家企业 TNFD 披露趋势、动态 PCF 试点结果及预计2026年10月发布的 ISSB 自然披露征求意见稿。
